# chinny-labs

Open-source apps and tools I build because I wanted them, and think someone else might too.

| Project | What it is |
| :--- | :--- |
| [**goldberry**](https://github.com/chinny-labs/goldberry) | Self-hosted allowance tracker for kids: jars, goals, and real-price investing. One container; SQLite or Postgres. |
| [**copperkeep**](https://github.com/copperkeep/copperkeep) | A learning platform where kids write and run Python in the browser, get graded, and build mastery. |
| [**phomv**](https://github.com/phomv/phomv) | Fast CLI that organizes photos into date-based folders from their EXIF data. |
| [**traceling**](https://github.com/chinny-labs/traceling) | Turns coloring-page PDFs into light-grey tracing pages for kids. |
| [**math**](https://github.com/chinny-labs/math) | Math Drill: arithmetic practice and printable worksheets, right in the browser. |

Games live in [**chinny-studios**](https://github.com/chinny-studios).

Issues and pull requests are welcome on any project. Each repo says how it's licensed.
